# 宇部市 公衆トイレマップ

宇部市が公開しているオープンデータ「公衆トイレ一覧」を使って作成したWebマップです。

山口県オープンデータカタログサイトから取得したデータをGeoJSONに変換し、Leafletを使ってマップ上に表示しています。

## Webマップ

👉 **[宇部市 公衆トイレマップを見る](https://crispytaffy.github.io/mymap2026/)**

## このマップについて

このマップは、ハンズオン教材
**「オープンデータでつくる、わたしのまちマップ ― はじめてのジオメディア」**
の完成サンプルとして作成しています。

オープンデータを、

**Excel → Python → GeoJSON → Leaflet → Webマップ**

という流れで加工・表示しています。

ハンズオン教材はこちら：

👉 [digitech2026](https://github.com/crispytaffy/digitech2026)

## 使用技術

* GeoJSON
